# 小程序图标说明

## 需要的图标文件

请将以下图标文件放到 `images/` 目录：

### TabBar 图标（48x48 像素 PNG）

1. **home.png** - 首页图标（灰色）
2. **home-active.png** - 首页图标（粉色选中）
3. **edit.png** - 记录图标（灰色）
4. **edit-active.png** - 记录图标（粉色选中）
5. **chart.png** - 统计图标（灰色）
6. **chart-active.png** - 统计图标（粉色选中）
7. **user.png** - 我的图标（灰色）
8. **user-active.png** - 我的图标（粉色选中）

## 临时方案

Demo 可以正常运行，但 TabBar 图标会显示为空白。您可以：

1. 使用微信开发者工具默认图标
2. 从 iconfont.cn 下载免费图标
3. 使用 AI 生成图标（推荐配色：#999999 灰色 / #FF6B81 粉色）

## 图标颜色参考

- 未选中：#999999
- 选中：#FF6B81
- 背景：#ffffff
