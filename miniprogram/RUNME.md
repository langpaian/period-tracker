## 🚀 快速启动

### 步骤 1：打开微信开发者工具

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开工具，选择「+」添加项目

### 步骤 2：导入项目

- **项目目录**：`/home/xf/.openclaw/workspace/projects/period-tracker/miniprogram`
- **AppID**：选择「测试号」或使用自己的 AppID
- **开发模式**：小程序
- **后端服务**：不使用云服务

### 步骤 3：编译运行

点击「编译」按钮，即可看到小程序运行效果！

## 💡 功能说明

### 首页
- 显示当前经期状态（经期中/排卵期/安全期）
- 预测下次经期和排卵日
- 快捷入口：记录今天、查看统计、个人中心

### 记录页
- 选择经血量：无/少量/中量/大量
- 选择症状：腹痛、头痛、乳房胀痛、疲劳、情绪波动、痘痘
- 添加备注（最多 200 字）
- 自动保存到本地存储

### 统计页
- 周期统计：平均/最短/最长周期
- 经期统计：平均经期天数、记录次数
- 症状统计：常见症状频次排序
- 清空数据功能

### 我的页
- 关于：版本信息、功能介绍
- 设置：周期长度配置（开发中）
- 反馈：联系开发者（开发中）

## 📝 测试数据

小程序使用本地存储，首次使用为空。您可以：

1. 点击「记一下」开始记录
2. 连续记录几天后，首页会显示预测信息
3. 统计页会根据记录自动计算

### 模拟测试
如需快速测试，可手动修改本地存储：
```javascript
// 在开发者工具控制台执行
wx.setStorageSync('periods', [
  { date: '2026-03-15', flow: 'medium' },
  { date: '2026-04-10', flow: 'light' }
])
```

## ⚠️ 注意事项

### TabBar 图标
- 当前 `images/` 目录为空，TabBar 图标会显示空白
- 临时方案：在 `app.json` 中注释掉 `tabBar` 配置
- 或从 [iconfont.cn](https://www.iconfont.cn) 下载免费图标

### AppID
- 测试使用「测试号」即可
- 如需发布，需替换为正式 AppID

### 真机预览
- 点击开发者工具「预览」按钮
- 使用微信扫码在手机上测试
